# The Full Syllabus — Build-While-Learn, End to End 🗺️

10 phases. We build the voice assistant and **open the hood on each concept as we use it** — so you get a working product *and* deep understanding, no dry upfront theory.

One atom per turn. `progress.md` tracks where you are.

| Phase | Theme | Atoms | You end up with |
|-------|-------|-------|-----------------|
| 1 | The **BRAIN** — text chat *(+ softmax)* | [phase-1-atoms.md](phase-1-atoms.md) | A working chatbot |
| 2 | **MEMORY & RAG** *(+ vectors, cosine)* | [phase-2-atoms.md](phase-2-atoms.md) | Answers from your data |
| 3 | The **EARS** — STT *(+ transformer sighting)* | [phase-3-atoms.md](phase-3-atoms.md) | Speak → text |
| 4 | The **MOUTH** — TTS | [phase-4-atoms.md](phase-4-atoms.md) | Text → voice |
| 5 | The **LOOP** — real-time | [phase-5-atoms.md](phase-5-atoms.md) | Hands-free spoken chat |
| 6 | **TOOLS & AGENTS** | [phase-6-atoms.md](phase-6-atoms.md) | An assistant that *acts* |
| 7 | **UNDER THE HOOD ★** — the deep dive | [phase-7-atoms.md](phase-7-atoms.md) | You can *build* an LLM |
| 8 | **FINE-TUNING** — Hugging Face | [phase-8-atoms.md](phase-8-atoms.md) | Your own custom model |
| 9 | The **PRODUCT** — API-first + SDK, MERN app as first consumer | [phase-9-atoms.md](phase-9-atoms.md) | An integratable assistant + web app |
| 10 | **CHEAP & SELLABLE** *(+ evals)* | [phase-10-atoms.md](phase-10-atoms.md) | A deployable product |

**🔧 = "open the hood"** atoms — where we pause the build to understand + implement the concept underneath.
