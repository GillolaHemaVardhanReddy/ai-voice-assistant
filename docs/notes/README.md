## How to use these (2 minutes, do it right)

Each atom is one card with four parts:

| Part | What it's for |
|---|---|
| 💡 **Idea** | One line. If you can say this out loud, you have the atom. |
| 💻 **The line that matters** | The 1–3 lines of code that ARE the concept. Everything else is plumbing. |
| ⚠️ **Gotcha** | The thing that bit you, or would have. This is the highest-value part. |
| ❓ **Self-test** | Answer it *before* opening the toggle. Opening it first is how you fool yourself. |

**The revision loop that actually works:** read only the 💡 lines top-to-bottom (60 seconds for a whole phase). Any line that feels fuzzy → open that card fully. Don't read cards you already own.
