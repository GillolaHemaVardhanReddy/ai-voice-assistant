How we travel it

⚛️ One atom per turnIdea → you do → it runs → one check question. Nothing moves until it lands.
🧮 Math gets its own sub-atomPicture → real numbers → formula → code. Never symbols first.
🖊️ Spec first, code secondYou get the spec and a blank file. Acharya's version only appears after yours exists.
🔁 Recall warm-up every sessionThree questions, no peeking. A blank is a win — failed retrieval is what makes it stick.
