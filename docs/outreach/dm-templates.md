# LinkedIn DM templates

DMs get read more than email and take less than they deserve. But LinkedIn punishes volume —
**5 a week, audited, and never the same paragraph twice.**

⚠️ He approves every send. ⚠️ No placeholders, no unverified numbers.

## Sequence that works
1. **Follow** them (not connect). Read their last 3 posts.
2. **Comment** on one, substantively — a question or a real observation. Not "Great post!"
3. **Wait 2-3 days.**
4. **Connect with a note** (see below). 200-character limit — this is the whole battle.
5. If accepted, **wait a day**, then the real message.

Skipping to step 4 works too, just worse. Never skip to step 5.

---

## Connection note (200 chars max — count them)

**A. audited**
```
Hi <<name>> — I ran 20 integrator questions through <<Company>>'s docs search this weekend
as a retrieval test. Interesting results. Building a free RAG bot for one company and
yours is my pick. Happy to share either way.
```

**B. after commenting on their post**
```
Hi <<name>> — commented on your <<topic>> post. I build RAG retrieval systems and publish
the numbers. Doing one full build free for a company with real docs; <<Company>> is top of
my list. Would love to connect.
```

**C. shortest, if the two above run long**
```
Hi <<name>> — I tested <<Company>>'s docs search against a RAG system I built. Want to send
you what I found? Nothing to sign up for.
```

## Message 1, after they accept

Keep it to phone-screen length. **Ask a question at the end — a message with no question gets no reply.**

```
Thanks for connecting, <<name>>.

Quick context: I build payment integrations at Way2News, and I've spent the last two months
building a RAG retrieval system from scratch — embeddings, reranking, a calibrated relevance
cutoff, a golden test set — publishing the numbers as I go, including the experiment that
improved nothing.

This weekend I ran 20 real integrator questions against <<Company>>'s docs search. It found
the right page for <<6>>. Mine answered <<17>> with citations, and abstains on the <<4>>
your docs don't cover.

90-second demo on your own docs: <<link>>

I'm building the full thing for one company, free — no fee, full handover, you'd only pay
the model API afterwards. I want the production experience more than a first invoice.

Is docs search something you're actually feeling pain on, or is it fine and I'm solving
a problem you don't have?
```

That last question is deliberate. It gives them an easy honest out, which is exactly why
people answer it.

## Warm DM — someone who engaged with his article
Highest-conversion message in the file. Do not pitch in the first line.
```
Hi <<name>> — thanks for the <<comment/like>> on the reranking write-up.

Curious, since you're on the <<their role/company>> side: <<a real question about their
setup — "did the reranker actually move your numbers, or did you find the same flat
result?">>

I'm about to run the same method on someone else's docs corpus for free — happy to send
you what comes out of it.
```

---

## Follow-up (once, after ~7 days)
```
<<name>> — no worries if this isn't a fit, just closing the loop. If docs search isn't the
pain right now, I'd still take a pointer to anyone whose is. <<link>> stays up either way.
```

## Do not
- Send a wall of text. LinkedIn shows ~3 lines before "see more" — the number goes in line 2.
- Send a voice note or a video note cold.
- Use "I hope this message finds you well."
- Pitch in the connection note AND the first message AND the follow-up. Pitch once.
- Send the same message to two people at one company. They talk.
